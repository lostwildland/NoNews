# NoNews

## Platform
Native macOS app built on NetNewsWire (AppKit and WebKit article rendering); shared data and iOS support for cross-device continuity. English product interface initially. Article and user prompt languages remain user-controlled.

## Audience and job
People following many sources who need to find information relevant to their own standards, understand selected material and carry it into research or work. Existing IO owner needs lossless continuity; new users need understandable setup without operating a separate backend.

## Product truth
NNW remains the main reader: accounts, subscriptions, folders, sync, list/detail, read/unread, Star, search, menus and keyboard navigation. Optional IO augments the same articles with validated materials, Curator scoring, Editor drafts, Yep/Nope, batch workflows, integrations and recovery. All current IO capabilities must have a destination; existing functionality is not cut to simplify the surface.

## Confirmed interaction
First available evaluation opens Curator. Existing IO result rendering and material/Draft tabs remain. Yep stays; Nope advances within current list. Human decision, read, Star and external collection are independent. No recommendation learning. Existing IO filters/Quick views are retained, no new custom Smart Feed editor. No added Draft list preview. No requirement to finish a Draft before using an integration.

## Configuration
Reusable Curator/Editor prompts each bind model/service or Magpie target; credentials remain centralized. Feed settings choose prompts, automation and thresholds. Existing personal choices become explicit grouped settings with usable defaults, impact previews and migration preservation. Safety validation and data protection are invariants, not optional switches.

## Design authority
Preserve NNW's native composition and Apple platform conventions. Use native system controls, SF Symbols, semantic colors and system Liquid Glass for supported navigation/controls; maintain an uncluttered legible reading surface. Linear/Notion/Arc are references for product clarity, not visual templates to imitate. Reduce Transparency/Motion and VoiceOver/keyboard support are required. macOS versions without Liquid Glass retain native fallback.

## Delivery
All active IO functions plus complete historical database/assets migration and new IO-data sync. No separately deployed IO/FreshRSS required for new users. No arbitrary workflow builder, recommendation learning or newly invented ASR. Full migration, real integration/sync readback and native UI evidence are required for final acceptance; static source evidence is not production proof.
