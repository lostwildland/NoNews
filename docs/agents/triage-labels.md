# Triage labels

Canonical roles map directly to these GitHub labels:

- `needs-triage`: maintainer evaluation needed.
- `needs-info`: waiting for information from the reporter.
- `ready-for-agent`: fully specified and ready for autonomous work.
- `ready-for-human`: requires human implementation.
- `wontfix`: will not be actioned.

Reuse existing labels. These roles apply to implementation triage;
wayfinding maps and decision tickets use only `wayfinder:*` labels.
