# 阅读呈现与内容处理分别定义

2026-10-25 用户确认：阅读呈现与处理方案分开，按内容提供合理默认组合；改变布局不改变评分规则，也不触发采集。这样同一种阅读布局可承载不同材料要求，同一内容也可按用户偏好阅读或播放，而无需把两套复杂设置直接暴露给用户。

该决定未确定媒介分类全集；提示词独立复用、不强制 Kit 的决定见 ADR 0004。

## 列表呈现基线

首版列表的 Curator 呈现沿用 IO，默认按内容时间倒序，排序交互参考 FreshRSS。用户未接受新增的 Draft 状态及一两行摘要预览方案，不将其列为首版要求；完整稿件在 Draft Tab 查看。具体移入 NNW 的列表布局仍待设计。

分数可作为用户主动选择的排序或筛选条件，不默认覆盖时间顺序。上述列表信息与状态仅用于阅读判断，不改变处理规则或触发采集。

详情页首版继续采用分层 Tab。原有 Score Tab 面向用户改名为 **Curator**，与处理角色统一；首次打开已有结果时进入 Curator，沿用 IO 展示提示词结果的方式，不额外要求将提示词、处理时间等元数据常驻。Draft、原文及其他材料保持独立 Tab；处理失败或材料不足时在 Draft Tab 明确说明状态和下一步，同时保留可用材料阅读。
