# 提示词独立复用，来源持有处理策略

用户确认：Curator 与 Editor 提示词分别具名保存、跨来源复用、支持复制修改，来源可独立组合两者，不再要求绑定为一个 Kit。提示词负责判断与写作指令；来源设置负责自动运行及继续处理的阈值，支持多来源批量设置，以兼顾复用与不同来源的投入策略。

修改默认影响后续处理，不自动重跑历史；保存时说明受影响来源。历史内容通过单独的重新评估／重新生成入口选择范围，先预览再执行，并保留旧结果。已排队及运行中任务采用哪个配置版本的边界尚待确定。

## 提示词编辑体验

设置中提供统一的提示词入口，分为 Curator 与 Editor；每份显示名称、内容、所选服务及模型（Magpie 为目标）和使用它的来源。模型与提示词一起配置，具体边界见 [ADR 0005](0005-user-connected-ai-services-including-magpie.md)。来源设置支持选择、新建或跳转编辑；修改共享提示词时显示受影响来源，并提供复制后修改。

用户定义判断标准、评分尺度内的含义及写作要求，系统负责必要的输出格式与校验。编辑器说明输入材料与预期输出，用户无需维护结构化输出格式；这不等于允许改变现有评分尺度或绕过输出校验。

首版不提供提示词试运行入口。此范围决定不影响已确认的正式重新评估／重新生成能力，也不取消编辑器的格式说明和校验。
