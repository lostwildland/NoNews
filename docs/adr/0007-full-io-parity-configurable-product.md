# 保留全部 IO 能力，转为可配置的原生 NoNews 产品

2026-10-27 用户确认。此决定覆盖此前仅交付最小闭环、单 Mac 新增数据和局部历史迁移的建议。

全部现行 IO 功能与能力必须在 NoNews 有对应，包括高级／维护能力，不能仅迁移 AI 主链。当前已退出的 UI 不作为现行能力冒充；新发现的活跃能力继续加入矩阵。NNW 仍为主阅读骨架，统一列表与详情，Curator／Editor 流程沿用 IO，不新增任意工作流编排。

个人偏好尽量转成分组设置、自定义提示词与可组合集成，保留旧用户的原有配置和默认行为，新用户获得可理解默认。Nope 清理策略可配置；正文、稿件和生命周期沿用 IO。材料核验、防覆盖、身份和数据完整性校验等保护不可关闭。Yep 与 Zotero、Obsidian 和期号采用的现有联动保留并显式配置，不再人为限制只有读完 Draft 后才可使用。

同一内容的不同提示词上下文可保存不同处理结果；身份归并和人的决定共享，历史运行的材料、提示词与模型不被后来配置替换。

应用管理必需处理组件，新用户不单独部署 IO 或 FreshRSS。同步属于此次必交付：沿用 NNW 适当接缝，明确账户类型、跨设备记录和离线冲突行为，不假装第三方 RSS 同步会自动携带自定义字段。完整个人数据库和资产迁移属于最终验收，副本演练后验证全量并保留源库回退；不能用样本迁入替代。

UI 遵循 NNW 与 Apple HIG，使用原生 Liquid Glass 及可用性回退，正文清晰可读。以具体任务、键盘／VoiceOver、深浅外观、减少动态／透明、窗口尺寸和错误恢复证据验收；“Apple 最佳 App 水准”是品质目标而非可自行授予的奖项。

用户授权按 spec → tickets → implement → code-review → commit/push 推进；一个 ticket 一个 GPT-6.1 Terra high 实现／测试负责人。具体工程和设计选择由主代理组织落实，十问结束，不再做重复功能访谈。
