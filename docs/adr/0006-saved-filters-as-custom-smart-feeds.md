# 首版沿用 IO 筛选与 Quick views，不提供自定义 Smart Feed

2026-10-25 用户撤回此前将保存筛选升级为自定义 Smart Feed 的方向，明确首版按现有 IO 的筛选功能设计。本决定取代本文件先前的自定义 Smart Feed 方案。

保留 IO 已有的组合筛选、已选条件展示、逐项清除，以及保存、套用和删除 Quick views；判断筛选融入同一面板，并使用已确认的英文 Yep／Nope 文案。具体行为以现有 IO 实现为基线，不增加保存来源范围、跟随文件夹成员、侧栏自定义 Smart Feed 或 Update Smart Feed / Save as New / Reset 这一套新规则。

NNW 原有内置 Smart Feeds 不在此次取消范围。首版不新增自定义规则编辑和 Smart Feed 持久化能力；IO 筛选向新产品的迁移尚未实现。
