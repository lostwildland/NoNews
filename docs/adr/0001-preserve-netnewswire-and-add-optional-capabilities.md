# 保留阅读能力，以产品需求决定设计

2026-10-25 用户确认：保留 NetNewsWire 全部现有功能，在此基础上增加 Information OS 能力；不配置 AI 或连接 Zotero／Obsidian，用户仍能正常订阅、阅读、搜索和收藏。设计以自身产品需求和用户体验为核心，从用户要完成的任务出发决定交互、模块与实现。

保留功能不等于保留原界面、操作路径或内部实现；同步上游的便利性不是设计约束。需要时可以重构，接受由此增加的上游合并维护工作；具体接入点与数据边界另行决定。Information OS 的能力全部盘点、逐项确定去向，不意味着全部原样进入首版。

2026-10-27 范围更新：用户要求全部当前活跃 IO 功能在 NoNews 对应后才能完成，见 ADR 0007；此前“不预先承诺首版全部进入”的边界由本次完整迁移目标覆盖。
