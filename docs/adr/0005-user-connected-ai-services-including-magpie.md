# 首版连接用户自己的 AI 服务，并支持 Magpie

用户确认：首版允许连接用户自己的 AI 服务及兼容接口网关，不提供由产品方代付的内置 AI 服务。Magpie 是必须支持的接入方式，以延续用户现有工作流；其他用户无需安装 Magpie 才能使用 AI 能力。

具体协议覆盖与兼容性验收另行制定，不承诺任意服务均可直接接入。

## 模型与提示词一起配置

用户在比较角色统一模型、提示词绑定及独立执行方案后，选择将提示词与模型放在一起配置。每份具名 Curator／Editor 提示词保存所选服务连接及模型；使用 Magpie 时选择网关目标，不将其名称等同于实际模型。来源选择提示词时同时确定该执行选择。

服务连接及凭据仍集中管理，提示词引用连接，不重复保存凭据。首版采用明确绑定，不增加角色默认与提示词覆盖的继承层级，也不增加来源级模型覆盖。由此支持同一角色的不同提示词使用不同模型。更换或删除服务时展示引用，不能留下静默失效引用或自动改用其他服务；最小实现可以要求先逐项替换／解绑，再删除，不要求额外的批量模型管理器。

此决定取代调研报告推荐的首版角色统一模型方案；报告保留为备选方案及取舍证据。修改共享提示词的模型与修改指令一样，需说明受影响来源，不自动重跑历史；一次保存必须让指令和执行绑定一致生效。运行与已有 Editor 目标固定值延续 IO，详见 [ADR 0004](0004-reusable-prompts-and-feed-processing-policy.md) 及[原生处理配置契约](../specs/native-processing-configuration.md)。文本历史恢复明确使用 Restore Text，保留当前显示的执行绑定，不暗示恢复旧模型或旧结果。
